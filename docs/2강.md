## 1. 취합 작업의 3원칙

> **1. 빠뜨리지 않는다   2. 임의로 수정하지 않는다   3. 없는 것은 지어내지 않는다**

흩어진 자료를 한 표로 모을 때 지켜야 할 것. 세 개 다 "AI가 알아서 잘 해주겠지"로 두면 깨지는 지점이라, 프롬프트에 명시적으로 박아야 한다.

| 원칙 | 깨지는 모양 | 프롬프트에 박는 법 |
|---|---|---|
| 빠뜨리지 않는다 | 중복 제거하다 실제 주문까지 날림 | "어느 한 곳에라도 있는 건 절대 빠뜨리지 마" + 끝나고 줄 수 검산 |
| 임의로 수정하지 않는다 | 값을 보기 좋게 고쳐버림 | 형식 통일 기준을 미리 지정 (날짜는 `YYYY-MM-DD`로 등) |
| 없는 것은 지어내지 않는다 | 빈칸에 0을 채움 | "조항이 없으면 0이 아니라 빈칸으로 해" |

## 실습 1 — 주문 3개 파일 → 주문종합 (`1. Order/`)

웹주문(150행)·전화주문(140행)·제휴주문(120행)을 빈 양식인 주문종합.xlsx에 합치는 작업. 같은 주문번호가 파일 간에 겹쳐 있다.

### 프롬프트 1 — 먼저 규칙부터 읽히기

> 작업폴더에 주문 파일 세 개(웹주문, 전화주문, 제휴주문)랑 주문을 종합할 양식 주문종합 파일이 있어, 먼저 작업방법참고 파일의 작업방법 시트를 읽고, 각 칸 이름·형식이랑 합치는 규칙을 나한테 요약해서 말해봐. 아직 데이터를 종합하지는 마.

**핵심은 "아직 데이터를 종합하지는 마"** — 규칙을 제대로 읽었는지 먼저 확인하고 넘어가는 2단계 구성.

작업방법 시트가 준 규칙:

| 항목 | 내용 |
|---|---|
| 표준 컬럼(7칸) | 주문번호, 고객명, 상품명, 수량, 금액_원, 주문일, 주문채널 |
| 누락 금지 | 세 파일 중 어느 한 곳에라도 있는 주문은 빠뜨리지 않음 |
| 중복 | 같은 주문번호가 겹치면 한 행으로, 어느 채널에서 왔는지 주문채널에 기록 |
| 수량·금액 | 1000단위 구분기호(`,`) |
| 주문일 | `YYYY-MM-DD`로 통일 |
| 결측 | 금액이 비어 있으면 0을 채우지 말고 빈칸 |

참고 시트의 칸 매핑:

| 주문종합 | 웹주문 | 전화주문 | 제휴주문 |
|---|---|---|---|
| 주문번호 | 주문번호 | order_id | 협력사주문ID |
| 고객명 | 고객명 | name | 구매자 |
| 상품명 | 상품 | item | 품목 |
| 수량 | 수량 | qty | 개수 |
| 금액_원 | 금액 | amount | 결제액 |
| 주문일 | 주문일시 | date | 일자 |

읽고 나서 되물은 것 3가지:

1. 참고 시트는 `매출액`·`주문일자`인데 실제 주문종합 헤더는 `금액_원`·`주문일` — 실제 파일 헤더 기준으로 감
2. 주문일 원본 형식이 3가지 (`2026-01-08 15:00` 텍스트 / 엑셀 날짜값 / `01/12/2026` 텍스트). 제휴는 앞자리가 전부 1, 뒷자리는 31까지 나와서 **MM/DD/YYYY**로 판정
3. 주문채널 표기값과, 겹친 주문의 값이 파일마다 다를 때 어느 쪽을 쓸지는 규칙에 없음

### 프롬프트 2 — 실제 통합

> 제안한 내용대로 하고 이제 세 파일의 데이터를 작업방법대로 합쳐서 주문종합 파일에 채워줘.

**결과**: 410줄 → 268행.

| 주문채널 | 건수 |
|---|---|
| 웹주문 | 80 |
| 전화주문 | 54 |
| 웹주문, 전화주문, 제휴주문 | 49 |
| 제휴주문 | 41 |
| 전화주문, 제휴주문 | 23 |
| 웹주문, 전화주문 | 14 |
| 웹주문, 제휴주문 | 7 |

기간 2026-01-01 ~ 01-31, 합계 수량 2,712 / 금액 153,236,000원.

### 프롬프트 3 — 검산

> 작업이 제대로 완료 되었는지 확인해보자. 원본 세 파일의 주문 줄 수를 각각 세고 다 더해줘. 그중 같은 주문번호가 여러 파일에 겹친 건이 몇 건인지, 그래서 중복을 접으면 통합표가 몇 줄이어야 맞는지 계산해줘. 그 숫자가 방금 만든 통합주문 시트 줄 수랑 같은지 확인해줘. 다르면 빠진 주문번호를 찾아서 알려줘.

**"3개 파일 주문 행 수의 합계 − 중복 주문으로 제거된 행 수 = 주문종합 파일 주문 행 수"** 를 AI에게 직접 계산시켜 대조하는 방식.

| 겹침 | 건수 |
|---|---|
| 웹 ∩ 전화 | 63 |
| 웹 ∩ 제휴 | 56 |
| 전화 ∩ 제휴 | 72 |
| 세 곳 모두 | 49 |

```
150 + 140 + 120 − 63 − 56 − 72 + 49 = 268
중복으로 제거된 행 = 410 − 268 = 142
```

**결과**: 기대 268 = 실제 268. 누락 0건, 원본에 없는 주문번호 0건, 내부 중복 0건.

## 실습 2 — 계약서 PDF 8건 → 계약종합.xlsx (`2. contract/`)

비정형(PDF) → 표. 이쪽이 "데이터 만들기"의 원형.

### 프롬프트

> 폴더의 PDF 계약서들을 읽고, 각 계약의 계약번호·계약명·상대방·계약기간·금액·자동갱신 여부를 뽑아서 표로 한 줄씩으로 정리해줘. 계약서에 안 적힌 항목은 지어내지 말고 비워둬. 특히 금액 조항이 없으면 0이 아니라 빈칸으로 해. 뽑아낸 결과는 '계약종합' 이라는 엑셀파일로 만들어줘

| 요소 | 프롬프트에서 해당하는 부분 |
|---|---|
| 입력 | 폴더의 PDF 계약서들 |
| 방법 | 계약번호·계약명·상대방·계약기간·금액·자동갱신 6개 항목 추출, 없으면 빈칸 |
| 출력 | '계약종합' 엑셀파일, 계약 1건 = 1행 |

**결과**: 8건 8행.

| 계약번호 | 계약명 | 상대방 | 계약기간 | 금액 | 자동갱신 |
|---|---|---|---|---:|:---:|
| CT-2026-001 | 사무용품 정기납품 계약 | ㈜한빛오피스 | 2026-08-07 ~ 2027-08-06 | 9,000,000 | 예 |
| CT-2026-002 | 청소용역 계약 | 청우클린서비스 | 2026-09-15 ~ 2027-09-14 | 7,200,000 | 아니오 |
| CT-2026-003 | IT장비 유지보수 계약 | ㈜테크메이트 | 2026-10-01 ~ 2027-09-30 | 15,400,000 | 예 |
| CT-2026-004 | 건물 경비 용역 계약 | 세이프가드시스템㈜ | 2026-07-20 ~ 2027-07-19 | 4,200,000 | 아니오 |
| CT-2026-005 | 사내식당 위탁운영 계약 | ㈜맛나푸드서비스 | 2026-11-01 ~ 2027-10-31 | **(빈칸)** | 예 |

**함정은 CT-2026-005** — 이 계약서만 제4조가 「계약금액」이 아니라 「정산 및 부대조건」이고, 본문이 "세부 정산 방식은 별도 협의를 통해 정한다"다. 제5조도 "구체적인 금액은 제4조에 따른 별도 협의로 정한다". 금액 조항 자체가 없으니 **0이 아니라 빈칸**. 프롬프트에 이 한 줄을 안 박았으면 0이 들어갔을 자리.

표기가 제각각이라 정규화한 것들:

| 항목 | 원문 형태 | 처리 |
|---|---|---|
| 금액 | `KRW 9,000,000` / `15,400,000원` / `금 칠백이십만원정` | 숫자값 + `#,##0` |
| 계약기간 | `2026년 8월 7일부터` / `2026.09.15부터` / `2026-10-01부터` / `유효기간은…` | `YYYY-MM-DD ~ YYYY-MM-DD` |
| 자동갱신 | "만료 30일 전 별도 해지 통보가 없을 시 자동으로 1년 연장" / "자동갱신되지 않으며 재계약이 필요" | 예 / 아니오 |

## 이 차시에서 건진 것

- **작업 지시서를 파일로 따로 주는 구조.** 프롬프트에 규칙을 다 적는 대신 `작업방법참고.xlsx`를 읽히고, 프롬프트는 "그 파일 읽고 규칙부터 요약해봐"만 시킨다. 규칙이 파일로 남아 재사용되고, 프롬프트는 짧아진다.
- **작업 전에 규칙을 복창시키는 2단계.** "아직 종합하지는 마"로 한 번 끊으면, 잘못 읽은 부분을 데이터가 망가지기 전에 잡는다. 실제로 이 단계에서 헤더 이름 불일치와 날짜 형식 3종을 먼저 발견했다.
- **검산을 AI에게 시키되 산식을 지정한다.** "제대로 했어?"가 아니라 "합계 − 중복 = 결과 줄 수"라는 식을 주고 대조시킨다. 자기가 만든 걸 자기가 검사하는 구조지만, 원본을 다시 세는 독립 경로라 의미가 있다.
- **"없으면 빈칸"은 반드시 말로 박아야 한다.** CT-2026-005처럼 8건 중 1건만 조항이 빠져 있으면, 나머지 7건 패턴에 맞춰 0을 채워넣기 딱 좋다.
- 요청 범위 밖은 보고만 함 — 계약금액의 **기준 기간이 계약마다 다르다** (총액 1건 / 연간 2건 / 월액 3건 / 애매 1건). 이 열은 단순 합산하면 안 되는데, 요청한 6개 열만 만들라고 해서 `금액 기준` 열은 추가하지 않았다.
