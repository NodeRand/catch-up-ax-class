# 0강 — 환경 세팅

**실습 자료**: `AX 직무 역량검사_강의자료(+실습대상)/0강/News_provider/` (강사 데모용 샘플 프로젝트)

## 내용

개발 환경 설치만 다루는 차시. 아래 4가지를 깔고 시작한다.

| 항목 | 용도 |
|---|---|
| VS Code | 편집기 겸 작업 환경 |
| Python | 데이터 처리 (엑셀·CSV 등) |
| Node.js | Claude Code 실행 런타임 |
| Claude Code | 실제 작업을 시키는 AI 에이전트 |

추가로 VS Code 확장 **Office Viewer** 설치 — `.xlsx` 같은 오피스 파일을 VS Code 안에서 바로 열어볼 수 있게 해준다. 강의 실습이 대부분 엑셀이라 결과를 눈으로 확인할 때 필요.

## 메모

이미 다 설치되어 있어 실습은 건너뜀.
