# catch-up-ax-class

외부 강의 **「AX 직무 역량검사」**(0강 ~ 8강) 스터디 저장소.
강사가 배포한 실습 파일을 **그 자리에서 직접 실습**하고, 그 과정에서 던진 프롬프트와 결과를 차시별 필기로 남긴다.

> 정답을 옮겨 적는 저장소가 아니라, **강의가 시킨 대로 해봤을 때 실제로 무엇이 나왔는지**를 남기는 기록이다.
> 강의 결과와 갈린 지점도 지우지 않고 그대로 적는다 (예: [docs/4강.md](docs/4강.md)의 "강의 결과와 갈린 지점").

## 저장소 구조

```
AX 직무 역량검사_강의자료(+실습대상)/   # 강사 배포 원본 = 그대로 실습하는 대상
  ├── 0강/ ~ 8강/                       # 차시별 실습 파일 (xlsx · csv · pdf · md)
  └── 결과참고/                         # 차시별 정답 예시 (1·2·3·4·6·7·8강)
docs/                                    # 차시별 필기본 (0강.md ~ 8강.md)
lecture-source/                          # 배포 zip 원본
CLAUDE.md                                # 이 저장소에서 AI 에이전트가 지켜야 할 작업 규칙
```

실습 파일은 **사본을 만들지 않고 제자리에서 수정**한다. 원본은 git에 커밋되어 있으므로 되돌릴 수 있고, `git diff`가 곧 실습 결과가 된다.

## 진행 방식

**한 차시 = 한 사이클.** 실습과 정리를 같은 세션에서 이어서 끝낸다.
무엇을 왜 그렇게 판단했는지는 실습을 돌린 그 자리에서만 온전히 남기 때문에, 둘을 다른 날로 쪼개지 않는다.

```
① 실습          강의가 준 프롬프트를 그대로 실행 → 전수 검증 → 표로 보고
② 정리          강의 슬라이드 캡처 + 실습 내용을 합쳐 docs/N강.md 작성
③ 커밋 · 푸시    add → 약속된 형식으로 커밋 → main push
```

### 실습할 때

- 강의가 시키는 프롬프트를 **그대로** 넣는다. 다듬거나 대신 개선하지 않는다 — 강의가 의도한 결과와 함정을 그대로 겪는 게 목적이다.
- 요청받은 열·범위만 손댄다. 작업 중 발견한 다른 이상(중복 행, 결측치, 날짜 형식 혼재 등)은 **고치지 말고 보고만** 한다. 이후 차시의 소재일 수 있다.
- **없는 값을 지어내지 않는다.** 원본에 없으면 0이나 임의값 대신 빈칸으로 둔다.
- 수정 후 전수 검증하고, 무엇이 몇 건 바뀌었는지 표로 남긴다.
- `결과참고/`는 정답지다. **제 손으로 끝내기 전에 열어보지 않는다.**

### 필기할 때

- **차시 1개 = md 파일 1개.** 파일명은 자료 폴더명(`0강`, `1강`, …)과 맞춘다.
- 한 파일은 보통 ① 강의 개념(슬라이드를 표·구조로 옮김) ② 실습(던진 프롬프트와 결과) 두 덩어리.
- 프롬프트는 **받아쓴 그대로** 인용 블록에 넣는다 (오타·비문 포함). 요약하거나 다듬지 않는다.
- 결과는 무엇이 몇 건 바뀌었는지 표로 짧게. 길게 해설하지 않는다.
- 완성 예시: [docs/1강.md](docs/1강.md), [docs/4강.md](docs/4강.md)

## 커밋 규칙

형식은 `{이모지}{타입}: [{N}강] {내용}`, 한국어로 쓴다.

```
🎉begin:   [0강] 프로젝트 시작 및 필기노트화 완료
🎨improve: [3강] 실습 및 필기노트화 완료
🧹chore:   .gitignore 추가 및 .DS_Store 추적 해제
📝docs:    강의자료 폴더명 변경 반영 (+실습대상)
```

커밋 전 `git status`로 **이번 차시 범위 밖의 변경이 섞여 있지 않은지** 확인한다.

## AI 에이전트로 작업할 때

이 저장소는 Claude Code로 실습하는 것을 전제로 한다. 위 규칙의 상세 버전은 [CLAUDE.md](CLAUDE.md)에 있고, 세션 시작 시 자동으로 읽힌다.

`0강/News_provider/`는 강사 데모용 샘플 프로젝트다. 실행하려면 `.env.example`을 `.env`로 복사해 키를 채운다 (`.env`는 커밋되지 않는다).
