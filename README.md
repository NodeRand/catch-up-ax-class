# AX 직무 역량검사 — 실습 기록

강의 **「AX 직무 역량검사」**(0강 ~ 8강)를 따라가며, 사무직 반복업무를 AI 에이전트로 처리하는 과정을 실습하고 정리한 저장소.

엑셀·PDF로 흩어진 실무 데이터를 대상으로 **취합 → 집계 → 분류 → 보고**까지 한 줄기로 다룬다.
차시별 실습 파일은 강사 배포 원본을 그대로 쓰고, 결과와 검산 과정은 [docs/](docs/)에 차시별로 남긴다.

---

## 강의가 정리한 반복업무 6가지 유형

신입 사무직의 반복업무는 결국 이 여섯 가지의 조합이라는 것이 강의 전체를 관통하는 뼈대다.

| 유형 | 입력 → 출력 | 한 줄 판별 |
|---|---|---|
| ① 데이터 만들기 (추출·파싱) | 비정형(PDF·이미지) → 표 | 구조 없던 걸 표로 만든다 |
| ② 자료 요약 (취합·통합) | 정형 다수 → 정형 하나 | 행을 보존하며 여러 파일을 합친다 |
| ③ 딱지 붙이기 (분류) | 텍스트 → 범주 라벨 | 이게 뭐냐 — 정답이 모호하다 |
| ④ 분석하기 (집계·분석) | 정형 → 요약·지표 | 행을 줄여 수치·인사이트로 |
| ⑤ 보고자료 만들기 (초안 작성) | 자료 → 새 산문 | 없던 보고서를 쓴다 |
| ⑥ 확인하고 수정하기 (검수) | 데이터 + 규칙 → 위반 판정 | 규칙에 맞냐 — 정답이 규칙이다 |

②와 ④는 **행이 보존되느냐 줄어드느냐**로, ③과 ⑥은 **정답이 모호하냐 규칙이냐**로 갈린다.

## 실습에서 나온 것들

### 2강 — PDF 계약서 8건을 표 한 장으로

계약서마다 표기가 제각각인 것을 하나의 형식으로 정규화했다.

| 항목 | 원문 | 정리 |
|---|---|---|
| 금액 | `KRW 9,000,000` · `15,400,000원` · `금 칠백이십만원정` | 숫자값 + `#,##0` |
| 계약기간 | `2026년 8월 7일부터` · `2026.09.15부터` · `2026-10-01부터` | `YYYY-MM-DD ~ YYYY-MM-DD` |
| 자동갱신 | "해지 통보가 없을 시 자동으로 1년 연장" | 예 / 아니오 |

8건 중 1건(CT-2026-005)은 계약금액 조항 자체가 없고 "별도 협의"로만 적혀 있었다.
나머지 7건 패턴을 따라 0을 채우기 딱 좋은 자리 — **없는 값은 지어내지 않고 빈칸으로 뒀다.**

### 3강 — 주문 9,389행 → 쿠폰 44개 성과표

취소 1,067행을 제외한 결제완료 8,322건을 쿠폰코드별로 집계.

| 검산 항목 | 결과 |
|---|---|
| 사용건수 총합 = 결제완료 행 수 | 8,322 = 8,322 (차이 0) |
| 취소 필터 적용 여부 | 709,453,463원 (결제완료) ≠ 967,528,590원 (전체) |
| 이익률 재계산 | 44행 전수 대조, 불일치 0 |

집계 결과 **44개 중 8개가 적자 쿠폰**이었고, 적자 폭이 −25%대 4건과 −7%대 4건 두 무리로 뚜렷이 갈렸다.
최대 적자인 CP19는 할인액(9,117,046원)이 매출이익(4,940,535원)의 약 2배.

### 4강 — VOC 520건 분류

문의유형 6종 · 감성 3종 · 위험대응 2종의 3축 분류.

| 문의유형 | 건수 | | 감성 | 건수 | | 위험대응 | 건수 |
|---|---:|---|---|---:|---|---|---:|
| 환불취소 | 111 | | 부정 | 265 | | 대응필요 | 68 |
| 배송지연 | 110 | | 중립 | 181 | | 공백 | 452 |
| 제품하자 | 91 | | 긍정 | 74 | | | |
| 사용문의 | 89 | | | | | | |
| 칭찬감사 | 89 | | | | | | |
| 기타 | 30 | | | | | | |

이 차시의 핵심은 분류 기준 문서를 **AI와 함께 먼저 만들고, 그 문서를 다음 작업의 입력으로 넣는** 2단 구조였다.
그 한 단계가 실제로 결과를 갈랐던 지점:

- 위험대응을 "제품 결함"이 아니라 **"안전 위험(화재·부상·감전·유해물질)"으로 좁힌 덕에** 68건이 170건으로 부풀지 않았다.
- 위험 68건 중 **18건은 감성이 긍정**이었다. "덕분에 잘 해결됐어요… 계속 지연되면 법적대응 할 생각입니다" 같은 문의 — 감성으로 걸렀으면 통째로 놓쳤을 건들.
- "그래도 상담원분이 친절해서 감사했어요" 같은 부수적 칭찬 52건을 본 사안에서 분리. 떼지 않으면 24건이 긍정으로 잘못 올라간다.
