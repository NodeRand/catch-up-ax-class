# 데이터통합

## 이 스킬을 쓰는 상황
사용자가 서로 다른 곳(웹/전화/제휴, 또는 여러 거래처)에서 받은 파일 여러 개를 들고 와서
"이거 하나로 합쳐줘", "비교할 수 있게 만들어줘"라고 요청할 때 사용한다.
파일 이름과 열 이름은 매번 다를 수 있으므로, 특정 파일명·열이름을 코드에 하드코딩하지 않는다.

## 절차

1. **파일 탐색**: 주어진 폴더의 파일 목록과 확장자(.xlsx/.csv)를 확인하고, 각 파일을 읽어 첫 행(헤더)과 상위 몇 행을 살펴본다.
2. **열 의미 파악**: 각 파일의 열 이름이 무엇을 뜻하는지 추론한다(예: `order_id`/`주문번호`/`협력사주문ID`는 모두 "주문번호"를 가리킴). 값의 형식(날짜 표기, 금액에 콤마 포함 여부, 인코딩)도 함께 확인한다.
3. **표준 칸 매핑 제안**: 통합할 표준 칸 목록을 정하고, 각 원본 파일의 열이 표준 칸 중 어디에 대응하는지 매핑표를 만들어 사용자에게 보여준다.
4. **사용자 확인**: 매핑이 맞는지 사용자에게 확인받는다. 애매한 열(용도를 알 수 없는 열, 표준 칸에 없는 열)은 임의로 넘겨짚지 말고 사용자에게 묻는다.
5. **통합**: 확인된 매핑대로 모든 파일을 표준 칸 형식(날짜는 YYYY-MM-DD, 금액은 콤마 제거한 숫자)으로 변환해 하나의 표로 합친다. 동일 키(예: 주문번호)가 여러 파일에 겹치면 중복을 제거하고 한 줄만 남긴다.
6. **검산**: 통합 전 각 파일의 행 수 합계와 중복 제거 건수, 통합 후 행 수가 서로 맞는지 계산해서 사용자에게 표로 보여준다. 금액 합계도 통합 전후로 비교한다.

## 원칙

- **빠뜨리지 않기**: 원본에 있는 행은 하나도 누락하지 않는다. 제외한 행이 있다면 이유(중복 등)를 명시한다.
- **바꾸지 않기**: 원본 값(고객명, 상품명, 금액 등)을 임의로 고치거나 반올림하지 않는다. 형식만 표준 칸 규격에 맞춘다.
- **지어내지 않기**: 원본에 없는 값(예: 빠진 날짜, 빠진 담당자)을 추측해서 채우지 않는다.
- **빈칸 ≠ 0**: 원본에 값이 없으면 빈칸으로 둔다. 0이나 임의값으로 채우면 나중에 진짜 0과 구분이 안 된다.

## 비개발자용 사용법
1. 합치고 싶은 파일들을 한 폴더에 모아 둔다.
2. Claude에게 "이 폴더의 파일들을 하나로 합쳐줘"라고 말한다.
3. Claude가 보여주는 열 매핑표를 확인하고, 맞으면 "네, 진행해줘"라고 답한다.
4. 통합 결과 파일과 검산표를 받는다. 행 수가 예상과 다르면 원인(중복, 빠진 파일 등)을 먼저 확인한다.
