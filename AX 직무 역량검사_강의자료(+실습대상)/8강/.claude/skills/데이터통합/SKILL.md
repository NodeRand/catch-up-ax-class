# 데이터통합

## 언제 쓰나

같은 종류의 표가 파일 여러 개로 흩어져 있고, 그걸 한 표로 봐야 할 때.
채널별 주문, 거래처별 견적, 지점별 실적처럼 **"출처는 다른데 담긴 내용은 같은 종류"**인 자료가 대상이다.

파일명과 열 이름은 매번 다르다. **어떤 파일이 올지 모른다는 전제로 동작한다** — 파일명이나 열 이름을 미리 정해두지 않는다.

## 절차

### 1. 폴더에서 표 파일 찾기
- 지정된 폴더의 `.xlsx` · `.xls` · `.csv`를 전부 찾는다. 대상을 미리 정해두지 않는다.
- 임시 파일(`~$`로 시작)과 **이전 실행에서 만든 결과물**은 제외한다. 자기 출력을 다시 먹으면 행이 불어난다.
- CSV는 인코딩을 확인한다(UTF-8 / CP949).

### 2. 각 열의 의미 파악
열 이름만 보지 않고 **값을 함께 본다.** 이름이 달라도 같은 것을 가리키는 경우가 대부분이다.

- 건별 고유 식별자 → 번호 칸 (`주문번호` / `order_id` / `협력사주문ID`)
- 사람·거래처 이름 → 이름 칸 (`고객명` / `name` / `구매자`)
- 물건 이름 → 품목 칸 (`상품` / `item` / `품목` / `자재명`)
- 개수를 나타내는 정수 → 수량 칸 (`수량` / `qty` / `개수` / `주문수량`)
- 돈 → 금액 칸 (`금액` / `amount` / `결제액` / `단가` / `개당단가`)
- 날짜 → 날짜 칸 (`주문일시` / `date` / `일자` / `납기일` / `납품예정일`)

### 3. 표준 칸 매핑 제안
- 이번 작업의 표준 칸 목록을 정한다. **표준 칸은 자료 종류에 따라 달라진다** — 주문이면 주문번호·고객명·상품명·수량·금액·주문일·출처, 견적이면 품목·규격·수량·단가·납기·업체처럼.
- 각 파일의 열이 어느 표준 칸에 대응하는지 **매핑표를 만들어 사용자에게 보여준다.**

### 4. 사용자에게 확인받기
**매핑이 애매하면 지어내지 말고 묻는다.**

- 표준 칸에 대응시킬 수 없는 열이 있을 때
- 한 표준 칸에 후보 열이 둘 이상일 때
- 날짜·금액 표기가 판독되지 않을 때 (특히 `01/15/2026`이 월-일인지 일-월인지)

매핑표를 확인받은 뒤에 5번으로 넘어간다. 확인 없이 통합하면 틀린 매핑이 전체 결과에 번진다.

### 5. 통합
- 날짜는 `YYYY-MM-DD`로 통일한다. 시각(시:분)은 버린다.
- 금액은 콤마를 제거하고 숫자만 남긴다.
- 출처 칸에 그 행이 **어느 파일에서 왔는지** 적는다.
- 같은 키(주문번호 등)가 여러 파일에 겹치면 한 줄만 남긴다. 출처는 먼저 등장한 파일 기준.
- 키가 없는 자료(견적처럼 같은 품목이 여러 업체에 있는 경우)는 중복 제거 대신 **비교되게 나란히 모은다.**

### 6. 행 수 검산
통합이 끝나면 반드시 검산해서 **표로 보여준다.**

- 통합 후 행 수 = (각 파일 행 수의 합) − (중복으로 제거된 건수)
- 금액 합계가 통합 전후로 맞는지 (중복분은 한 번만 포함)
- 날짜 형식 위반 건수, 빈칸 건수

숫자가 안 맞으면 결과를 내놓기 전에 원인을 먼저 밝힌다.

## 원칙

### 1. 빠뜨리지 않기
원본에 있는 행은 하나도 누락하지 않는다. 뺀 행이 있으면 이유(중복 등)를 반드시 밝힌다.

### 2. 바꾸지 않기
원본 값을 고치거나 반올림하지 않는다. **형식만** 표준 칸 규격에 맞춘다. 이름의 오탈자, 어색한 상품명도 그대로 둔다 — 고치는 건 다른 작업이다.

### 3. 지어내지 않기
원본에 없는 값을 추측해서 채우지 않는다. 빈칸은 빈칸으로 둔다. **빈칸을 0으로 채우면 나중에 진짜 0과 구분할 수 없다.**

## 비개발자용 사용법

1. 합치고 싶은 파일들을 한 폴더에 모아 둔다.
2. "이 폴더 파일들 하나로 합쳐줘"라고 말한다.
3. 열 매핑표가 나오면 맞는지 확인하고 답한다. 틀린 칸이 있으면 그것만 짚어주면 된다.
4. 결과 파일과 검산표를 받는다. **행 수가 예상과 다르면 결과를 쓰기 전에 원인부터 확인한다.**
